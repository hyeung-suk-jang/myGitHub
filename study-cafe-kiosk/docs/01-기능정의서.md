# 스터디 카페 키오스크 시스템 - 기능 정의서

## 1. 개요

### 1.1 시스템 목적
스터디 카페 운영을 위한 키오스크 시스템으로, 사용자의 좌석 선택, 이용권 구매, 입퇴실 관리 및 관리자의 운영 현황 모니터링을 지원합니다.

### 1.2 주요 목표
- 사용자의 편리한 좌석 선택 및 이용권 구매
- 실시간 좌석 현황 확인
- 효율적인 입퇴실 관리
- 관리자의 종합적인 운영 현황 모니터링

## 2. 사용자 기능

### 2.1 회원 관리

#### 2.1.1 회원가입 (FR-001)
**기능 설명**: 신규 사용자가 회원으로 가입할 수 있습니다.

**입력 정보**:
- 이름 (username)
- 이메일 (email)
- 전화번호 (phone)
- 비밀번호 (password)

**처리 로직**:
1. 입력 정보 유효성 검증
2. 이메일 중복 확인
3. 사용자 정보 저장
4. 자동 로그인 처리

**출력**:
- 성공: 회원가입 완료 및 메인 페이지로 이동
- 실패: 에러 메시지 표시 (중복 이메일 등)

#### 2.1.2 로그인 (FR-002)
**기능 설명**: 등록된 사용자가 시스템에 로그인할 수 있습니다.

**입력 정보**:
- 이메일
- 비밀번호

**처리 로직**:
1. 이메일/비밀번호 검증
2. 사용자 인증
3. 세션 생성
4. 권한 확인 (일반 사용자/관리자)

**출력**:
- 성공: 메인 페이지로 이동
- 실패: 에러 메시지 표시

#### 2.1.3 로그아웃 (FR-003)
**기능 설명**: 로그인된 사용자가 로그아웃할 수 있습니다.

**처리 로직**:
1. 현재 세션 종료
2. 사용자 정보 초기화
3. 로그인 페이지로 이동

### 2.2 좌석 관리

#### 2.2.1 좌석 조회 (FR-004)
**기능 설명**: 실시간 좌석 현황을 확인할 수 있습니다.

**표시 정보**:
- 좌석 번호 (1~30)
- 좌석 타입 (1인석/2인석/단체석)
- 층 정보 (1층/2층)
- 좌석 상태 (이용 가능/사용 중/예약됨)

**좌석 구성**:
- 1인석: 1~20번 (총 20석)
- 2인석: 21~28번 (총 8석)
- 단체석: 29~30번 (총 2석)
- 1층: 1~15번 (총 15석)
- 2층: 16~30번 (총 15석)

#### 2.2.2 좌석 선택 (FR-005)
**기능 설명**: 사용 가능한 좌석을 선택할 수 있습니다.

**처리 로직**:
1. 이용 가능한 좌석 확인
2. 좌석 선택
3. 선택 정보 임시 저장
4. 이용권 선택 페이지로 이동

**제약 조건**:
- 이용 가능 상태의 좌석만 선택 가능
- 사용자당 1개 좌석만 선택 가능

### 2.3 이용권 관리

#### 2.3.1 이용권 조회 (FR-006)
**기능 설명**: 구매 가능한 이용권 목록을 확인할 수 있습니다.

**이용권 종류**:
| 이용권명 | 타입 | 이용시간 | 가격 | 설명 |
|---------|------|---------|------|------|
| 2시간 이용권 | hourly | 2시간 (120분) | 4,000원 | 2시간 자유롭게 이용 가능 |
| 4시간 이용권 | hourly | 4시간 (240분) | 7,000원 | 4시간 자유롭게 이용 가능 |
| 종일 이용권 | daily | 12시간 (720분) | 15,000원 | 12시간 자유롭게 이용 가능 |
| 주간 이용권 | weekly | 1주일 (10,080분) | 80,000원 | 1주일 무제한 이용 가능 |
| 월간 이용권 | monthly | 1개월 (43,200분) | 250,000원 | 1개월 무제한 이용 가능 |

#### 2.3.2 이용권 선택 (FR-007)
**기능 설명**: 원하는 이용권을 선택할 수 있습니다.

**처리 로직**:
1. 이용권 선택
2. 선택 정보 임시 저장
3. 결제 페이지로 이동

### 2.4 결제

#### 2.4.1 결제 처리 (FR-008)
**기능 설명**: 선택한 이용권에 대한 결제를 진행합니다.

**결제 수단**:
- 카드 결제
- 간편 결제
- 현금 결제

**처리 로직**:
1. 선택한 좌석 및 이용권 정보 확인
2. 결제 수단 선택
3. 결제 처리
4. 결제 정보 저장
5. 세션 생성 및 좌석 배정

**출력**:
- 성공: 결제 완료 및 입실 처리, 마이페이지로 이동
- 실패: 에러 메시지 표시

### 2.5 입퇴실 관리

#### 2.5.1 입실 처리 (FR-009)
**기능 설명**: 결제 완료 후 자동으로 입실이 처리됩니다.

**처리 로직**:
1. 결제 완료 확인
2. 세션 생성
   - 시작 시간 기록
   - 남은 시간 초기화 (이용권 시간)
   - 세션 상태: 'active'
3. 좌석 상태 변경: 'available' → 'occupied'
4. 사용자 현재 세션 정보 저장

#### 2.5.2 퇴실 처리 (FR-010)
**기능 설명**: 사용자가 이용을 종료하고 퇴실합니다.

**처리 로직**:
1. 현재 세션 확인
2. 종료 시간 기록
3. 실제 이용 시간 계산
4. 세션 상태 변경: 'active' → 'completed'
5. 좌석 상태 변경: 'occupied' → 'available'
6. 이용 내역 생성 및 저장

### 2.6 마이페이지

#### 2.6.1 현재 이용 정보 조회 (FR-011)
**기능 설명**: 현재 이용 중인 정보를 확인할 수 있습니다.

**표시 정보**:
- 좌석 번호
- 이용권명
- 시작 시간
- 남은 시간
- 퇴실 버튼

#### 2.6.2 이용 내역 조회 (FR-012)
**기능 설명**: 과거 이용 내역을 확인할 수 있습니다.

**표시 정보**:
- 좌석 번호
- 이용권명
- 이용 시작 시간
- 이용 종료 시간
- 실제 이용 시간
- 결제 금액

**정렬 기준**: 최신 순

## 3. 관리자 기능

### 3.1 대시보드 (FR-013)
**기능 설명**: 스터디 카페 운영 현황을 실시간으로 모니터링합니다.

**표시 정보**:
- 전체 좌석 수
- 이용 가능 좌석 수
- 사용 중 좌석 수
- 총 매출 (누적)
- 오늘 매출
- 현재 이용 중인 사용자 수

### 3.2 좌석 관리 (FR-014)
**기능 설명**: 전체 좌석의 실시간 상태를 확인하고 관리합니다.

**표시 정보**:
- 좌석 번호
- 좌석 타입
- 층 정보
- 현재 상태
- 사용자 정보 (사용 중인 경우)

**가능한 작업**:
- 좌석 상태 조회
- 좌석별 사용 현황 확인

### 3.3 세션 관리 (FR-015)
**기능 설명**: 현재 진행 중인 모든 세션을 관리합니다.

**표시 정보**:
- 사용자명
- 좌석 번호
- 이용권명
- 시작 시간
- 남은 시간
- 세션 상태

**가능한 작업**:
- 세션 목록 조회
- 세션 상태 확인

### 3.4 이용 내역 관리 (FR-016)
**기능 설명**: 모든 사용자의 이용 내역을 조회하고 관리합니다.

**표시 정보**:
- 사용자 ID
- 좌석 번호
- 이용권명
- 시작 시간
- 종료 시간
- 이용 시간
- 결제 금액

**가능한 작업**:
- 전체 이용 내역 조회
- 기간별 필터링
- 사용자별 필터링
- 통계 확인

## 4. 비기능적 요구사항

### 4.1 성능
- 페이지 로딩 시간: 3초 이내
- 좌석 상태 업데이트: 실시간 반영
- 동시 사용자 지원: 최소 50명

### 4.2 보안
- 비밀번호 암호화 저장 (향후 백엔드 구현 시)
- 사용자 인증 및 권한 관리
- 관리자 페이지 접근 제어

### 4.3 사용성
- 직관적인 UI/UX
- 반응형 디자인 (모바일, 태블릿, 데스크톱)
- 한글 인터페이스

### 4.4 데이터 관리
- LocalStorage를 통한 데이터 영속화
- 브라우저 종료 후에도 로그인 상태 유지
- 데이터 일관성 보장

## 5. 제약사항

### 5.1 현재 버전
- 백엔드 API 없음 (Mock 데이터 사용)
- LocalStorage 기반 데이터 저장
- 실시간 타이머 미구현
- 실제 결제 게이트웨이 미연동

### 5.2 향후 개선 필요 사항
- 백엔드 API 연동
- 실시간 타이머 기능
- 푸시 알림 (시간 만료 알림)
- 실제 결제 시스템 연동
- 사물함 관리 기능
- 음료/간식 주문 시스템

## 6. 용어 정의

| 용어 | 정의 |
|-----|-----|
| 세션 (Session) | 사용자의 1회 이용 단위 (입실부터 퇴실까지) |
| 이용권 (Ticket) | 스터디 카페 이용을 위한 시간권 |
| 좌석 상태 | available(이용 가능), occupied(사용 중), reserved(예약됨) |
| 세션 상태 | active(이용 중), completed(완료), expired(만료) |
| Mock 데이터 | 실제 백엔드 없이 테스트용으로 사용하는 가상 데이터 |
