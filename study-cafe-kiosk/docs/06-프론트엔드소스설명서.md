### 3.3 RegisterPage
**위치**: `src/pages/RegisterPage.tsx`

**역할**: 신규 회원 가입

**주요 기능**:
1. 회원가입 폼 제공
2. 입력 유효성 검증
3. 회원가입 처리
4. 성공 시 자동 로그인 및 메인 페이지 이동

**사용하는 Store**:
- `useAuthStore`: register 액션

**Form 필드**:
| 필드 | 타입 | 검증 | 설명 |
|-----|------|------|------|
| username | text | required | 사용자 이름 |
| email | email | required, unique | 이메일 주소 |
| phone | tel | required | 전화번호 |
| password | password | required, min 6 | 비밀번호 |
| confirmPassword | password | required, match | 비밀번호 확인 |

**주요 로직**:
```typescript
const { register } = useAuthStore();
const [formData, setFormData] = useState({
  username: '',
  email: '',
  phone: '',
  password: '',
  confirmPassword: '',
});

const handleRegister = async (e: FormEvent) => {
  e.preventDefault();

  // 비밀번호 확인
  if (formData.password !== formData.confirmPassword) {
    setError('비밀번호가 일치하지 않습니다.');
    return;
  }

  const success = await register(
    formData.username,
    formData.email,
    formData.phone,
    formData.password
  );

  if (success) {
    navigate('/');  // 자동 로그인 후 메인으로
  } else {
    setError('이미 가입된 이메일입니다.');
  }
};
```

**유효성 검증**:
- 모든 필드 필수 입력
- 이메일 형식 검증
- 비밀번호 최소 6자
- 비밀번호 확인 일치 여부

**주요 기능**:

**사용하는 Store**:
- `useAuthStore`: 로그인 확인
- `useStudyCafeStore`: 좌석 목록, selectSeat

**좌석 배치**:
```
1층: 좌석 1-15
  - 1-15번 중 1-13: 1인석
  - 14-15번: 2인석

2층: 좌석 16-30
  - 16-20번: 1인석
  - 21-28번: 2인석
  - 29-30번: 단체석
```

**주요 로직**:
```typescript
const { user, isAuthenticated } = useAuthStore();
const { seats, selectSeat } = useStudyCafeStore();
const [selectedFloor, setSelectedFloor] = useState<number | 'all'>('all');

// 로그인 확인
useEffect(() => {
  if (!isAuthenticated) {
    navigate('/login');
  }
}, [isAuthenticated]);

// 층별 필터링
const filteredSeats = selectedFloor === 'all'
  ? seats
  : seats.filter(seat => seat.floor === selectedFloor);

// 좌석 선택
const handleSeatSelect = (seat: Seat) => {
  if (seat.status !== 'available') {
    alert('이용 가능한 좌석이 아닙니다.');
    return;
  }

  selectSeat(seat);
  navigate('/tickets');
};
```

**UI 구성**:
- 상단: 층 선택 탭 (전체/1층/2층)
- 중앙: 좌석 그리드
  - 좌석 번호
  - 좌석 타입 아이콘
  - 상태별 색상
    - 초록색: 이용 가능
    - 회색: 사용 중
- 하단: 범례 (좌석 타입 및 상태 설명)

**좌석 상태 색상**:

## 7. 라우팅 및 네비게이션

### 7.1 React Router 사용

```typescript
import { useNavigate } from 'react-router-dom';

const navigate = useNavigate();

// 페이지 이동
navigate('/seats');
navigate('/login');
navigate(-1);  // 뒤로가기
```

### 7.2 페이지 흐름

```
로그인하지 않은 경우:
  HomePage → LoginPage/RegisterPage → (로그인 후) → HomePage

좌석 선택 플로우:
  HomePage → SeatSelectPage → TicketSelectPage → PaymentPage → MyPage

관리자:
  HomePage → AdminPage
```

### 7.3 권한 체크 패턴

```typescript
// 로그인 확인
useEffect(() => {
  if (!isAuthenticated) {
    navigate('/login');
  }
}, [isAuthenticated]);

// 관리자 확인
useEffect(() => {
  if (!isAuthenticated || !user?.isAdmin) {
    navigate('/');
  }
}, [isAuthenticated, user]);
```
