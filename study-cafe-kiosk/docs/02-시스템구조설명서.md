# 스터디 카페 키오스크 시스템 - 시스템 구조 설명서

## 1. 개요

### 1.1 시스템 아키텍처
본 시스템은 **프론트엔드 중심의 SPA (Single Page Application)** 아키텍처로 구성되어 있으며, 현재 버전에서는 백엔드 API 없이 LocalStorage를 활용한 클라이언트 사이드 데이터 관리를 수행합니다.

### 1.2 기술 스택

#### 프론트엔드
- **React 19.2.0**: UI 라이브러리
- **TypeScript 5.9.3**: 정적 타입 지원
- **Vite 7.2.4**: 빌드 도구 및 개발 서버
- **React Router DOM 7.10.1**: 클라이언트 사이드 라우팅
- **Zustand 5.0.9**: 경량 상태 관리 라이브러리
- **Tailwind CSS 3.4.19**: 유틸리티 우선 CSS 프레임워크
- **React Icons 5.5.0**: 아이콘 라이브러리

#### 개발 도구
- **ESLint**: 코드 품질 관리
- **PostCSS**: CSS 후처리
- **Autoprefixer**: CSS 벤더 프리픽스 자동 추가

### 2.2 레이어별 상세 설명

#### 2.2.1 UI Layer (Presentation Layer)
사용자 인터페이스를 담당하며, React 컴포넌트로 구성됩니다.

**책임**:
- 사용자 입력 처리
- 화면 렌더링
- 라우팅 관리
- 이벤트 핸들링

**주요 컴포넌트**:
- **HomePage**: 메인 페이지, 로그인/회원가입 진입점
- **LoginPage**: 로그인 폼
- **RegisterPage**: 회원가입 폼
- **SeatSelectPage**: 좌석 선택 인터페이스
- **TicketSelectPage**: 이용권 선택 인터페이스
- **PaymentPage**: 결제 처리 페이지
- **MyPage**: 사용자 현황 및 이용 내역
- **AdminPage**: 관리자 대시보드

#### 2.2.2 State Management Layer
Zustand를 사용한 전역 상태 관리 레이어입니다.

**특징**:
- Redux보다 간결한 API
- Persist middleware를 통한 자동 LocalStorage 동기화
- TypeScript 타입 안정성

**Store 구성**:

1. **useAuthStore**
   - 사용자 인증 상태 관리
   - 로그인/로그아웃/회원가입 로직
   - 현재 로그인 사용자 정보

2. **useStudyCafeStore**
   - 좌석 정보 관리
   - 이용권 정보 관리
   - 세션 관리
   - 이용 내역 관리
   - 비즈니스 로직 처리

#### 2.2.3 Data Layer
LocalStorage를 통한 데이터 영속화 레이어입니다.

**저장소**:
- `auth-storage`: 인증 정보
- `study-cafe-storage`: 스터디 카페 운영 데이터

**데이터 흐름**:
1. Store의 상태 변경 발생
2. Persist middleware가 자동으로 LocalStorage에 저장
3. 브라우저 새로고침 시 LocalStorage에서 자동 복원

### 3.2 주요 엔티티

#### User (사용자)
- 시스템 사용자 정보
- 일반 사용자 및 관리자 구분

#### Seat (좌석)
- 스터디 카페 좌석 정보
- 30석 (1층 15석, 2층 15석)
- 타입별 분류 (1인석, 2인석, 단체석)

#### Ticket (이용권)
- 시간별 이용권 정보
- 5가지 타입 (2시간, 4시간, 종일, 주간, 월간)

#### Session (이용 세션)
- 사용자의 현재 이용 세션
- 실시간 상태 추적

#### UsageHistory (이용 내역)
- 완료된 이용 기록
- 통계 및 내역 조회용

## 6. 상태 관리 전략

### 6.1 Store 분리 원칙

**useAuthStore** (인증 상태)
- 사용자 인증 관련 상태만 관리
- 로그인, 로그아웃, 회원가입 액션
- 단일 책임 원칙 준수

**useStudyCafeStore** (비즈니스 로직)
- 스터디 카페 운영 관련 모든 상태 관리
- 좌석, 이용권, 세션, 내역 관리
- 복합 비즈니스 로직 처리

### 6.2 데이터 영속화

Zustand의 persist middleware 활용:
```typescript
persist(
  (set, get) => ({ /* state & actions */ }),
  {
    name: 'storage-name', // LocalStorage key
  }
)
```

**장점**:
- 자동 저장/복원
- 브라우저 새로고침 후에도 상태 유지
- 설정 간편

## 8. 확장성 고려사항

### 8.1 백엔드 API 연동 준비
현재 Store의 액션 함수들을 API 호출로 쉽게 전환 가능하도록 설계:

```typescript
// 현재 (Mock)
login: async (email, password) => {
  const user = mockUsers.find(...);
  set({ user, isAuthenticated: true });
}

// 향후 (API)
login: async (email, password) => {
  const response = await fetch('/api/auth/login', {
    method: 'POST',
    body: JSON.stringify({ email, password })
  });
  const user = await response.json();
  set({ user, isAuthenticated: true });
}
```
