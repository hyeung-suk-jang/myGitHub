# 스터디 카페 키오스크 시스템 - 백엔드 소스 설명서

## 1. 개요

### 1.1 현재 상태
본 시스템은 **현재 백엔드가 없는 프론트엔드 전용 애플리케이션**입니다. 백엔드 역할은 Zustand Store와 LocalStorage를 통해 클라이언트 사이드에서 처리됩니다.

### 1.2 문서 구성
이 문서는 두 부분으로 구성됩니다:
1. **현재 구현**: Zustand Store를 통한 클라이언트 사이드 로직 설명
2. **향후 구현 가이드**: 실제 백엔드 API 서버 구현 방안

---

## 3. useAuthStore (인증 관리)

### 3.1 파일 위치
`src/store/useAuthStore.ts`

### 3.2 역할
사용자 인증 및 회원 관리를 담당합니다.

### 3.3 상태 (State)

```typescript
interface AuthState {
  user: User | null;           // 현재 로그인한 사용자
  isAuthenticated: boolean;    // 인증 상태
}
```

### 3.4 액션 (Actions)

#### 3.4.1 login
**목적**: 사용자 로그인 처리

**함수 시그니처**:
```typescript
login: (email: string, password: string) => Promise<boolean>
```

**현재 구현**:
```typescript
login: async (email: string, password: string) => {
  const user = mockUsers.find(
    (u) => u.email === email && u.password === password
  );

  if (user) {
    set({ user, isAuthenticated: true });
    return true;
  }
  return false;
}
```

**로직**:
1. mockUsers 배열에서 이메일과 비밀번호 일치 확인
2. 일치하는 사용자 있으면:
   - Store에 사용자 정보 저장
   - isAuthenticated를 true로 설정
   - return true
3. 없으면 return false

**향후 API 구현**:
```typescript
login: async (email: string, password: string) => {
  try {
    const response = await fetch('/api/auth/login', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ email, password }),
    });

    if (!response.ok) {
      return false;
    }

    const { user, token } = await response.json();

    // JWT 토큰 저장
    localStorage.setItem('token', token);

    set({ user, isAuthenticated: true });
    return true;
  } catch (error) {
    console.error('Login error:', error);
    return false;
  }
}
```

#### 3.4.2 register
**목적**: 신규 회원 가입 처리

**함수 시그니처**:
```typescript
register: (
  username: string,
  email: string,
  phone: string,
  password: string
) => Promise<boolean>
```

**현재 구현**:
```typescript
register: async (username, email, phone, password) => {
  // 이메일 중복 확인
  const existingUser = mockUsers.find((u) => u.email === email);
  if (existingUser) {
    return false;
  }

  // 새 사용자 생성
  const newUser: User = {
    id: String(mockUsers.length + 1),
    username,
    email,
    phone,
    password,
    isAdmin: false,
    createdAt: new Date(),
  };

  mockUsers.push(newUser);
  set({ user: newUser, isAuthenticated: true });
  return true;
}
```

**로직**:
1. 이메일 중복 체크
2. 중복 시 return false
3. 새 사용자 객체 생성
4. mockUsers에 추가
5. 자동 로그인 처리
6. return true

**향후 API 구현**:
```typescript
register: async (username, email, phone, password) => {
  try {
    const response = await fetch('/api/auth/register', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ username, email, phone, password }),
    });

    if (!response.ok) {
      return false;
    }

    const { user, token } = await response.json();
    localStorage.setItem('token', token);

    set({ user, isAuthenticated: true });
    return true;
  } catch (error) {
    console.error('Register error:', error);
    return false;
  }
}
```

**함수 시그니처**:

**구현**:
```typescript
updateSeatStatus: (seatId, status) => {
  set((state) => ({
    seats: state.seats.map((seat) =>
      seat.id === seatId ? { ...seat, status } : seat

  }));

```

**로직**:

**향후 API 구현**:
```typescript
updateSeatStatus: async (seatId, status) => {
  try {
    await fetch(`/api/seats/${seatId}`, {
      method: 'PATCH',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${localStorage.getItem('token')}`,
      },
      body: JSON.stringify({ status }),
    });

    // 낙관적 업데이트
    set((state) => ({
      seats: state.seats.map((seat) =>
        seat.id === seatId ? { ...seat, status } : seat
      ),
    }));
  } catch (error) {
    console.error('Failed to update seat status:', error);
  }
}
```

#### 4.4.3 세션 관련

##### startSession
**목적**: 새 세션 시작 (입실 처리)

**함수 시그니처**:
```typescript
startSession: (userId: string, seatId: string, ticketId: string) => void
```

**구현**:
```typescript
startSession: (userId, seatId, ticketId) => {
  const ticket = get().tickets.find((t) => t.id === ticketId);
  if (!ticket) return;

  const newSession: Session = {
    id: `session-${Date.now()}`,
    userId,
    seatId,
    ticketId,
    startTime: new Date(),
    endTime: null,
    remainingMinutes: ticket.duration,
    status: 'active',
  };

  set((state) => ({
    sessions: [...state.sessions, newSession],
  }));

  get().updateSeatStatus(seatId, 'occupied');
}
```

**로직**:
1. ticketId로 이용권 조회
2. 없으면 종료
3. 새 세션 객체 생성:
   - id: timestamp 기반
   - startTime: 현재 시간
   - endTime: null (이용 중)
   - remainingMinutes: 이용권의 duration
   - status: 'active'
4. sessions 배열에 추가
5. 좌석 상태를 'occupied'로 변경

**향후 API 구현**:
```typescript
startSession: async (userId, seatId, ticketId) => {
  try {
    const response = await fetch('/api/sessions', {
      method: 'POST',
      headers: {
        'Content-Type': 'application/json',
        'Authorization': `Bearer ${localStorage.getItem('token')}`,
      },
      body: JSON.stringify({ userId, seatId, ticketId }),
    });

    const newSession = await response.json();

    set((state) => ({
      sessions: [...state.sessions, newSession],
    }));

    // 좌석 상태 업데이트는 서버에서 처리되므로 재조회
    await fetchSeats();
  } catch (error) {
    console.error('Failed to start session:', error);
  }
}
```

##### endSession
**목적**: 세션 종료 (퇴실 처리)

**함수 시그니처**:
```typescript
endSession: (sessionId: string) => void
```

**구현**:
```typescript
endSession: (sessionId) => {
  const session = get().sessions.find((s) => s.id === sessionId);
  if (!session) return;

  const endTime = new Date();
  const duration = Math.floor(
    (endTime.getTime() - session.startTime.getTime()) / (1000 * 60)
  );

  // 세션 상태 업데이트
  set((state) => ({
    sessions: state.sessions.map((s) =>
      s.id === sessionId
        ? { ...s, endTime, status: 'completed' as const }
        : s
    ),
  }));

  // 좌석 상태 복원
  get().updateSeatStatus(session.seatId, 'available');

  // 이용 내역 생성
  const seat = get().seats.find((s) => s.id === session.seatId);
  const ticket = get().tickets.find((t) => t.id === session.ticketId);

  if (seat && ticket) {
    const history: UsageHistory = {
      id: `history-${Date.now()}`,
      userId: session.userId,
      seatNumber: seat.number,
      ticketName: ticket.name,
      startTime: session.startTime,
      endTime,
      duration,
      amount: ticket.price,
    };
    get().addUsageHistory(history);
  }
}
```

**로직**:
1. sessionId로 세션 조회
2. 종료 시간 기록
3. 실제 이용 시간 계산 (밀리초 → 분)
4. 세션 상태를 'completed'로 변경
5. 좌석 상태를 'available'로 복원
6. 좌석 및 이용권 정보 조회
7. 이용 내역 생성 및 저장

**향후 API 구현**:
```typescript
endSession: async (sessionId) => {
  try {
    const response = await fetch(`/api/sessions/${sessionId}/end`, {
      method: 'POST',
      headers: {
        'Authorization': `Bearer ${localStorage.getItem('token')}`,
      },
    });

    const { session, usageHistory } = await response.json();

    // Store 업데이트
    set((state) => ({
      sessions: state.sessions.map((s) =>
        s.id === sessionId ? session : s
      ),
      usageHistory: [...state.usageHistory, usageHistory],
    }));

    // 좌석 상태 재조회
    await fetchSeats();
  } catch (error) {
    console.error('Failed to end session:', error);
  }
}
```

## 5. 향후 백엔드 구현 가이드

### 5.1 기술 스택 권장사항

#### 5.1.1 Option 1: Node.js + Express
```
- Runtime: Node.js 18+
- Framework: Express.js
- ORM: Prisma 또는 TypeORM
- Database: PostgreSQL 또는 MySQL
- Auth: JWT (jsonwebtoken)
- Validation: Zod 또는 Joi
```

#### 5.1.2 Option 2: Node.js + NestJS
```
- Runtime: Node.js 18+
- Framework: NestJS
- ORM: TypeORM (내장)
- Database: PostgreSQL
- Auth: Passport + JWT
- Validation: class-validator (내장)
```

### 5.2 API 엔드포인트 설계

### 5.3 데이터베이스 마이그레이션

#### 5.3.1 Prisma 스키마 예시

```prisma
// schema.prisma

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

generator client {
  provider = "prisma-client-js"
}

model User {
  id        String   @id @default(uuid())
  username  String
  email     String   @unique
  phone     String
  password  String
  isAdmin   Boolean  @default(false)
  createdAt DateTime @default(now())

  sessions      Session[]
  usageHistory  UsageHistory[]
  payments      Payment[]

  @@index([email])
}

model Seat {
  id      String     @id @default(uuid())
  number  Int        @unique
  type    SeatType
  status  SeatStatus @default(available)
  floor   Int

  sessions Session[]

  @@index([status, floor])
}

enum SeatType {
  single
  double
  group
}

enum SeatStatus {
  available
  occupied
  reserved
}

model Ticket {
  id          String     @id @default(uuid())
  name        String
  type        TicketType
  duration    Int
  price       Int
  description String?

  sessions Session[]
  payments Payment[]

  @@index([type])
}

enum TicketType {
  hourly
  daily
  weekly
  monthly
}

model Session {
  id               String        @id @default(uuid())
  userId           String
  seatId           String
  ticketId         String
  startTime        DateTime      @default(now())
  endTime          DateTime?
  remainingMinutes Int
  status           SessionStatus @default(active)

  user   User   @relation(fields: [userId], references: [id], onDelete: Cascade)
  seat   Seat   @relation(fields: [seatId], references: [id])
  ticket Ticket @relation(fields: [ticketId], references: [id])

  @@index([userId, status])
  @@index([seatId, status])
}

enum SessionStatus {
  active
  completed
  expired
}

model UsageHistory {
  id         String   @id @default(uuid())
  userId     String
  seatNumber Int
  ticketName String
  startTime  DateTime
  endTime    DateTime
  duration   Int
  amount     Int

  user User @relation(fields: [userId], references: [id], onDelete: Cascade)

  @@index([userId, startTime(sort: Desc)])
}

  ticket Ticket @relation(fields: [ticketId], references: [id])
```

#### 5.4.1 JWT 미들웨어 (Express)

```typescript
// middleware/auth.ts
import jwt from 'jsonwebtoken';
import { Request, Response, NextFunction } from 'express';

interface JwtPayload {
  userId: string;
  email: string;
  isAdmin: boolean;
}

export const authMiddleware = (
  req: Request,
  res: Response,
  next: NextFunction
) => {
  try {
    const token = req.headers.authorization?.split(' ')[1];

    if (!token) {
      return res.status(401).json({ error: 'No token provided' });
    }

    const decoded = jwt.verify(
      token,
      process.env.JWT_SECRET!
    ) as JwtPayload;

    req.user = decoded;
    next();
  } catch (error) {
    return res.status(401).json({ error: 'Invalid token' });
  }
};

export const adminMiddleware = (
  req: Request,
  res: Response,
  next: NextFunction
) => {
  if (!req.user?.isAdmin) {
    return res.status(403).json({ error: 'Admin access required' });
  }
  next();
};
```

#### 5.4.2 로그인 컨트롤러

```typescript
// controllers/authController.ts
import bcrypt from 'bcrypt';
import jwt from 'jsonwebtoken';
import { PrismaClient } from '@prisma/client';

const prisma = new PrismaClient();

export const login = async (req: Request, res: Response) => {
  try {
    const { email, password } = req.body;

    // 사용자 조회
    const user = await prisma.user.findUnique({
      where: { email },
    });

    if (!user) {
      return res.status(401).json({ error: 'Invalid credentials' });
    }

    // 비밀번호 확인
    const isPasswordValid = await bcrypt.compare(password, user.password);
    if (!isPasswordValid) {
      return res.status(401).json({ error: 'Invalid credentials' });
    }

    // JWT 생성
    const token = jwt.sign(
      {
        userId: user.id,
        email: user.email,
        isAdmin: user.isAdmin,
      },
      process.env.JWT_SECRET!,
      { expiresIn: '7d' }
    );

    // 비밀번호 제외하고 반환
    const { password: _, ...userWithoutPassword } = user;

    res.json({
      user: userWithoutPassword,
      token,
    });
  } catch (error) {
    console.error('Login error:', error);
    res.status(500).json({ error: 'Internal server error' });
  }
};

export const register = async (req: Request, res: Response) => {
  try {
    const { username, email, phone, password } = req.body;

    // 이메일 중복 확인
    const existing = await prisma.user.findUnique({
      where: { email },
    });

    if (existing) {
      return res.status(400).json({ error: 'Email already exists' });
    }

    // 비밀번호 해싱
    const hashedPassword = await bcrypt.hash(password, 10);

    // 사용자 생성
    const user = await prisma.user.create({
      data: {
        username,
        email,
        phone,
        password: hashedPassword,
      },
    });

    // JWT 생성
    const token = jwt.sign(
      {
        userId: user.id,
        email: user.email,
        isAdmin: user.isAdmin,
      },
      process.env.JWT_SECRET!,
      { expiresIn: '7d' }
    );

    const { password: _, ...userWithoutPassword } = user;

    res.status(201).json({
      user: userWithoutPassword,
      token,
    });
  } catch (error) {
    console.error('Register error:', error);
    res.status(500).json({ error: 'Internal server error' });
  }
};
```

### 5.5 세션 관리 구현 예시

```typescript
// controllers/sessionController.ts
import { PrismaClient } from '@prisma/client';
import { Request, Response } from 'express';

const prisma = new PrismaClient();

export const startSession = async (req: Request, res: Response) => {
  try {
    const { seatId, ticketId } = req.body;
    const userId = req.user!.userId;

    // 트랜잭션으로 처리
    const result = await prisma.$transaction(async (tx) => {
      // 이미 활성 세션이 있는지 확인
      const existingSession = await tx.session.findFirst({
        where: {
          userId,
          status: 'active',
        },
      });

      if (existingSession) {
        throw new Error('Already have an active session');
      }

      // 좌석 확인
      const seat = await tx.seat.findUnique({
        where: { id: seatId },
      });

      if (!seat || seat.status !== 'available') {
        throw new Error('Seat not available');
      }

      // 이용권 조회
      const ticket = await tx.ticket.findUnique({
        where: { id: ticketId },
      });

      if (!ticket) {
        throw new Error('Ticket not found');
      }

      // 세션 생성
      const session = await tx.session.create({
        data: {
          userId,
          seatId,
          ticketId,
          remainingMinutes: ticket.duration,
          status: 'active',
        },
        include: {
          seat: true,
          ticket: true,
        },
      });

      // 좌석 상태 변경
      await tx.seat.update({
        where: { id: seatId },
        data: { status: 'occupied' },
      });

      return session;
    });

    res.status(201).json(result);
  } catch (error: any) {
    console.error('Start session error:', error);
    res.status(400).json({ error: error.message });
  }
};

export const endSession = async (req: Request, res: Response) => {
  try {
    const { id } = req.params;
    const userId = req.user!.userId;

    const result = await prisma.$transaction(async (tx) => {
      // 세션 조회
      const session = await tx.session.findFirst({
        where: {
          id,
          userId,  // 본인의 세션만
        },
        include: {
          seat: true,
          ticket: true,
        },
      });

      if (!session) {
        throw new Error('Session not found');
      }

      if (session.status !== 'active') {
        throw new Error('Session is not active');
      }

      const endTime = new Date();
      const duration = Math.floor(
        (endTime.getTime() - session.startTime.getTime()) / (1000 * 60)
      );

      // 세션 종료
      const updatedSession = await tx.session.update({
        where: { id },
        data: {
          endTime,
          status: 'completed',
        },
      });

      // 좌석 상태 복원
      await tx.seat.update({
        where: { id: session.seatId },
        data: { status: 'available' },
      });

      // 이용 내역 생성
      const usageHistory = await tx.usageHistory.create({
        data: {
          userId,
          seatNumber: session.seat.number,
          ticketName: session.ticket.name,
          startTime: session.startTime,
          endTime,
          duration,
          amount: session.ticket.price,
        },
      });

      return { session: updatedSession, usageHistory };
    });

    res.json(result);
  } catch (error: any) {
    console.error('End session error:', error);
    res.status(400).json({ error: error.message });
  }
};
```
